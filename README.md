# PAW Week 2

Kumpulan latihan dan proyek **Pemrograman Aplikasi Web (PAW) Week 2**. Repository ini menyimpan tiga folder proyek dengan susunan aslinya.

## Isi repository

| Folder | Deskripsi |
| --- | --- |
| `demoPHP/` | Contoh dasar PHP, seperti variabel, konstanta, kondisi, perulangan, dan array. |
| `Personal Web/` | Website personal statis yang dibuat dengan HTML, CSS, dan JavaScript. |
| `user_data/` | Formulir data pengguna berbasis PHP dengan validasi dan tampilan hasil. |

## Menjalankan proyek

### `demoPHP/` dan `user_data/`

Jalankan melalui server PHP, misalnya XAMPP:

1. Letakkan folder proyek di dalam direktori `htdocs`.
2. Jalankan Apache dari XAMPP Control Panel.
3. Buka proyek di browser, misalnya `http://localhost/user_data/`.

Untuk menjalankan server PHP bawaan, buka terminal di folder proyek dan jalankan:

```bash
php -S localhost:8000
```

Lalu buka `http://localhost:8000` di browser.

### `Personal Web/`

Buka `Personal Web/index.html` di browser. Website ini tidak memerlukan proses build atau instalasi dependency.
